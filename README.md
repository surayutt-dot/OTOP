# ระบบบัญชีวิสาหกิจชุมชนกลุ่มแปรรูปสมุนไพรพื้นบ้าน ต.บ้านทราย อ.บ้านหมี่ จ.ลพบุรี 🌿

แอปพลิเคชันบันทึกบัญชีอย่างง่ายสำหรับวิสาหกิจชุมชน (Single-File Mobile Web App) พัฒนาขึ้นโดยอ้างอิงจากบทความวิจัย:
> **"แนวทางการพัฒนาศักยภาพวิสาหกิจชุมชนกลุ่มแปรรูปสมุนไพรพื้นบ้าน ในตำบลบ้านทราย อำเภอบ้านหมี่ จังหวัดลพบุรี"**  
> *วารสารบริหารธุรกิจและสังคมศาสตร์ มหาวิทยาลัยรามคำแหง ปีที่ 4 ฉบับที่ 3 (2564)*

---

## 🚀 วิธีเปิดใช้งาน

### 1. เปิดใช้งานในเครื่องคอมพิวเตอร์ทันที (ไม่ต้องติดตั้งโปรแกรมใดๆ)
- **ดับเบิลคลิกที่ไฟล์ `index.html`** ในโฟลเดอร์นี้เพื่อเปิดผ่าน Google Chrome, Microsoft Edge หรือเบราว์เซอร์ใดก็ได้ทันที!
- ข้อมูลที่บันทึก สินค้าที่เพิ่มใหม่ และรายการที่สร้างขึ้นจะถูกจำไว้ในเครื่องผ่าน `LocalStorage` แบบออฟไลน์ ปิดเปิดใหม่ข้อมูลไม่หาย

---

### 2. วิธีนำขึ้น GitHub และเปิดใช้งานบนมือถือ (GitHub Pages)
ไฟล์ที่ต้องนำขึ้น GitHub สำหรับเปิดใช้งานผ่านเบราว์เซอร์บนมือถือ มีเพียง 3 ไฟล์:
1. **`index.html`** (ไฟล์หลักของระบบ)
2. **`leaf.svg`** (ไอคอน Favicon)
3. **`README.md`** (คู่มือและคำอธิบาย)

**ขั้นตอนนำขึ้น GitHub:**
```bash
git init
git add index.html leaf.svg README.md .gitignore
git commit -m "Add Ban Sai Herb Accounting App"
git branch -M main
git remote add origin https://github.com/<ชื่อผู้ใช้ GitHub>/<ชื่อคลังข้อมูล>.git
git push -u origin main
```
**การเปิด GitHub Pages:**
1. ไปที่แท็บ **Settings** ของ Repository บน GitHub $\rightarrow$ เมนูด้านซ้ายเลือก **Pages**
2. ตรงหัวข้อ **Branch** เลือก `main` โฟลเดอร์ `/ (root)` แล้วกด **Save**
3. รอ 1 นาที จะได้ลิงก์ เช่น `https://<ชื่อผู้ใช้>.github.io/<ชื่อคลังข้อมูล>/`
4. เปิดลิงก์บนมือถือ แล้วกด **"เพิ่มไปยังหน้าจอโฮม (Add to Home Screen)"** จะได้ไอคอนแอปเสมือนแอปจริงบนมือถือ พร้อมใช้งานได้ทันที

## 🌿 ฟังก์ชันหลักที่พัฒนาขึ้น

1. **บันทึกรายการแบบง่าย ไม่ต้องรู้ระบบบัญชีคู่:**
   - 🟢 **+ รับเงิน (ขายสินค้า):**
     - สินค้าพื้นฐานตามงานวิจัย (เซรั่มหมักผม, น้ำมันมะพร้าว, แชมพู, สบู่, สเปรย์กันยุง)
     - ⭐ **ปุ่ม `+ เพิ่มสินค้าใหม่`:** สามารถกรอกชื่อสินค้า ราคาต่อหน่วย หน่วยนับ และเลือกไอคอนอีโมจิได้เองตามต้องการ
   - 🔴 **- จ่ายเงิน (ต้นทุน/ค่าใช้จ่าย):**
     - รายจ่ายพื้นฐานตามงานวิจัย (ซื้อขวด 200-300 ใบ, สมุนไพร, ค่าแรง 50 บ./คน, ค่าส่ง, ชำระคืนเงินกู้กองทุน 100k)
     - ⭐ **ปุ่ม `+ เพิ่มประเภทรายจ่ายใหม่`:** สามารถตั้งชื่อรายจ่าย และเลือกระบุหมวดว่าเป็น **ต้นทุนผลิต (COGS)** หรือ **ค่าใช้จ่ายดำเนินงานทั่วไป (OPEX)** เพื่อให้งบกำไรขาดทุนคำนวณได้อย่างถูกต้อง
2. **สรุปสิ้นวัน (Daily Cashbook):**
   - คำนวณเงินสดยกมา + รับวันนี้ - จ่ายวันนี้ = เงินสดคงเหลือสิ้นวัน
   - ตรวจนับเงินสดจริงในกระเป๋าเทียบกับยอดระบบ
   - ปุ่ม **"คัดลอกส่งเข้า LINE กลุ่ม"** คลิกเดียวได้ข้อความพร้อมส่ง
3. **งบการเงินอัตโนมัติ (Financial Statements):**
   - 📈 **งบกำไรขาดทุน (Income Statement):** คำนวณรายได้ หักต้นทุนผลิต (COGS) รวมทั้งรายการที่เพิ่มขึ้นเอง ได้กำไรขั้นต้น หักค่าใช้จ่ายดำเนินงาน (OPEX) ได้กำไรสุทธิ
   - ⚖️ **งบดุล (Balance Sheet):** แสดงสินทรัพย์ (เงินสด), หนี้สิน (เงินกู้กองทุน 100k คงเหลือ), ทุนหุ้นสมาชิก (25 คน x 100฿) และกำไรสะสม พร้อมตรวจสอบสมดุล 100%
   - 👥 **ระบบจัดสรรเงินปันผลสมาชิก 25 คน:** แบ่งปันผล 70%, สำรองเงินหมุนเวียน 20%, กองทุนสวัสดิการ 10%
4. **โหมดผู้สูงอายุ (Senior Mode):**
   - ปุ่มสลับขนาดตัวหนังสือใหญ่ เพื่อความสบายตาของสมาชิกชุมชน
